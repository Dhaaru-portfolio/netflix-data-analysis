# Netflix Data Analysis 📺

Analysis of 8807 movies & TV shows from Netflix to find insights about content trends.

### 📊 Project Overview
- Dataset: Netflix titles (8807 records)
- Goal: Find content trends, popular genres, country-wise distribution

### 📈 Visualizations Included
1.  **Movies vs TV Shows Count** - 69% Movies, 31% TV Shows
2.  **Content Added Trend (2008-2021)** - Huge growth after 2015
3.  **Top 10 Genres on Netflix** - International Movies & Dramas on top
4.  **Top 10 Countries** - US leads with 2800+ titles

### 🛠️ Tools Used
Python, Pandas, Matplotlib, Seaborn, Google Colab
